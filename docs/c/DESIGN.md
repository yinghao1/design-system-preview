# RUNDA ToC 移动端设计组件系统规范

> 版本 1.6.0 | 基于 RUNDA iOS 应用 UI 截图逆向分析  
> 适用平台：iOS (iPhone)  
> 设计分辨率：390×852pt (3x → 1170×2556px)

---

## 0. 开发规范（必读）

**⚠️ 所有新页面创建和新功能开发必须遵循以下规则：**

1. **优先使用设计系统组件**  
   查阅 `COMPONENTS.md` 确认是否有现成组件，禁止重复造轮。

2. **严格参考 Origin 视觉风格**  
   `design-system/Origin/` 包含 42 张 APP 实际截图，所有 UI 实现必须与截图保持视觉一致性。

3. **遵循设计令牌**  
   所有样式值必须引用 `design-tokens.json` 或本文档定义的令牌，禁止硬编码。

4. **完整开发流程与验收标准**  
   详见 **[`DEVELOPMENT-RULES.md`](./DEVELOPMENT-RULES.md)** — 包含强制性检查清单、视觉验收流程、违规处理。

## 1. 设计原则

| 原则 | 说明 | 实践指导 |
|------|------|----------|
| **浅色为主** | 以暖灰为基底，清爽通透，突出内容 | 背景色使用 #FAFAFA/#F4F4F5，卡片用纯白，通过阴影区分层级 |
| **蓝色聚焦** | 单一强调色（品牌青蓝 #2A7F8B）引导注意力 | 仅用于 CTA、链接、进度、关键状态，不滥用 |
| **卡片承载** | 信息以卡片为单元组织，边界清晰 | 卡片间距 12pt，内边距 16pt |
| **呼吸感** | 大量留白，信息密度适中 | 段落间距 ≥ 24pt，列表项间距 ≥ 8pt |
| **渐进展示** | 复杂信息分层呈现，避免一次性过载 | 折叠/展开、步骤指示器、骨架屏 |
| **触觉反馈** | 所有可交互元素有明确的状态变化 | 按压缩放 0.96、高亮背景、haptic |

### 2.2 语义色彩映射（默认 Light 主题）

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FAFAFA` | 暖灰底色，主屏幕背景 |
| 次级背景 | `#F4F4F5` | 列表底色、分区 |
| 卡片/容器背景 | `#FFFFFF` | 内容承载面（通过阴影/边框区分层级） |
| 暖色面 | `#F3E9D4` | 特殊卡片、品牌区域 |
| 抬升面（弹窗/Sheet） | `#FFFFFF` | 浮层背景 + 阴影 |
| 主文字 | `#18181B` | 标题、正文 |
| 次要文字 | `#52525B` | 描述、时间戳 |
| 占位/禁用文字 | `#A1A1AA` | 输入提示 |
| 分割线 | `#E4E4E7` | 列表分隔 |
| 强调/CTA | `#2A7F8B` | 按钮、链接、进度、选中态 |
| 强调按压态 | `#1D6770` | 按钮按下 |
| 选中背景 | `rgba(42,127,139,0.08)` | Tab 选中、列表高亮 |

### 2.3 色彩使用规则

1. **60-30-10 法则**：60% 暖灰背景 + 30% 白色面/深色文字 + 10% 蓝色强调
2. **对比度要求**：主文字与背景对比度 ≥ 7:1 (AAA)；次要文字 ≥ 4.5:1 (AA)
3. **状态色不做背景大面积填充**，仅用于小标签/图标/进度条
4. **渐变仅用于品牌元素**（启动页、高级功能入口），不用于普通按钮
5. **层级区分**：浅色主题通过阴影（而非背景色差）区分层级
6. **暖色面**：用于品牌相关区域（如任务卡片背景），营造自然温暖感
7. **背景纹理**：全局使用点状纹理（grain），与 B 端产品保持一致的视觉质感

### 2.4 背景纹理（与 B 端共享）

页面背景叠加微弱点状纹理，增加质感层次，避免纯色平面感：

```css
background-image: radial-gradient(rgba(0,0,0,0.018) 1px, transparent 1px);
background-size: 3px 3px;
background-attachment: fixed;
```

- **点色**：`rgba(0,0,0,0.018)` — 极低不透明度，肉眼几乎不可见但增加质感
- **点径**：1px
- **间距**：3px × 3px 网格
- **附着**：fixed（滚动时纹理不动，增加深度感）
- **适用范围**：页面 body 背景层，卡片/弹窗内部不叠加

### 2.5 跨产品设计语言一致性

以下视觉元素与 B 端 RUNDA ToB Design System (v2.6) 保持完全一致：

| 共享元素 | B 端令牌路径 | C 端令牌路径 | 说明 |
|----------|-------------|-------------|------|
| 中性色阶 | `color.ink.50~950` | `color.primitive.neutral` | 11 级灰阶完全一致 |
| 背景纹理 | `effect.grain` | `effect.grain` | 相同参数 |
| 主色 500 | `color.cdx.500` | `color.primitive.primary.500` | 同为 #2A7F8B |

- **标题不超过 2 行**，超出截断加省略号

- **中英混排**时英文使用 SF Pro，中文自动回退 PingFang SC
- **数字/金额**使用等宽数字特性（Tabular Figures），大数字展示组件使用 `typography.scale.numeric*` token（Manrope 字族）
- **代码块**使用 SF Mono 14pt，行高 20pt，背景 `#121212`

## 4. 间距系统

### 4.1 基础网格

基于 **4pt 网格**，所有间距为 4 的倍数：

```
4 → 8 → 12 → 16 → 20 → 24 → 32 → 40 → 48 → 64 → 80
```

### 4.2 语义间距

| 场景 | 值 | 说明 |
|------|-----|------|
| 屏幕水平内边距 | 16pt | 左右安全区 |
| 卡片内边距 | 16pt | 上下左右统一 |
| 卡片间距 | 12pt | 垂直方向卡片间 |
| 区块间距 | 24pt | 不同功能区之间 |
| 列表项间距 | 8pt | 同类列表项之间 |
| 图标与文字间距 | — | 水平排列时 |
| 按钮内边距 | 14pt × 24pt | 垂直 × 水平 |
| 输入框内边距 | 12pt × 16pt | 垂直 × 水平 |
| 导航栏高度 | 44pt | 不含状态栏 |
| Tab 栏高度 | 49pt | 不含安全区 |
| 安全区顶部 | 59pt | 刘海屏状态栏 |
| 安全区底部 | 34pt | Home Indicator |

### 4.3 间距使用原则

1. **关联性原则**：相关元素间距小（8pt），无关元素间距大（24pt+）
2. **层级递进**：同级 8pt → 父子 12pt → 区块 24pt → 页面段 32pt+
3. **触摸目标**：最小可点击区域 44×44pt
4. **呼吸感**：列表首尾额外留 16pt 空间

## 5. 圆角系统

| 名称 | 值 | 应用场景 |
|------|-----|----------|
| xs | 4pt | 小标签、代码块 |
| sm | 8pt | 小按钮、输入框内嵌元素 |
| md | 12pt | 按钮、输入框、Toast |
| lg | 16pt | 卡片、缩略图 |
| xl | 20pt | 大卡片 |
| 2xl | 24pt | 弹窗、底部 Sheet |
| full | 9999pt | 胶囊按钮、头像、Chip、进度条 |

### 圆角规则

- **卡片统一 16pt**，不混用不同圆角值
- **按钮默认 12pt**，胶囊型用 full
- **嵌套圆角**：内层圆角 = 外层圆角 - 内边距（如卡片 16pt 内的按钮用 12pt）
- **底部 Sheet** 仅顶部两角圆角 24pt
- **头像/状态点**始终 full（正圆）

## 7. 动效系统

### 7.1 时长规则

| 类型 | 时长 | 场景 |
|------|------|------|
| 即时 | 100ms | 按钮按压、开关切换 |
| 快速 | 200ms | 淡入淡出、颜色变化 |
| 标准 | 300ms | 页面转场、弹窗出现 |
| 慢速 | 450ms | 复杂动画、列表重排 |
| 延展 | 600ms | 骨架屏脉冲、进度填充 |

### 7.2 缓动曲线

| 名称 | 曲线 | 用途 |
|------|------|------|
| 默认 | `ease` | 通用过渡 |
| 弹性 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Sheet 弹出、Toast 滑入 |
| 减速 | `ease-out` | 元素进入视口 |
| 加速 | `ease-in` | 元素离开视口 |

### 7.3 动效模式

| 模式 | 描述 | 参数 |
|------|------|------|
| 页面推入 | 从右向左滑入，前页缩小 | 300ms, easeInOut |
| Sheet 上滑 | 从底部弹出，带弹性 | 350ms, spring |
| 列表项出现 | 逐项淡入+上移 | 300ms, stagger 50ms |
| 骨架屏脉冲 | 明暗交替闪烁 | 1500ms, easeInOut, infinite |
| 进度条填充 | 从左到右平滑增长 | 600ms, easeOut |
| 按钮按压 | 缩放至 0.96 | 100ms, easeOut |
| Toast 通知 | 从顶部滑入 | 250ms, spring |
| Loading 加载 | 三星脉冲（大/中/小错峰缩放+透明度） | 大星 1733ms / 中星 1733ms 延迟 -240ms / 小星 1067ms, linear, infinite |

### 7.4 减弱动效

当系统开启「减弱动态效果」时：
- 所有过渡改为 **淡入淡出**（无位移）
- 时长减半
- 禁用弹性曲线
- 骨架屏改为静态占位

### 12.2 趋势色规则

| 趋势 | 色值 | 用途 |
|------|------|------|
| 上升 | `#02C456` | 数值变好、达标 |

> **注意**：「上升 = 绿」仅在「数值越大越好」的指标（步数/睡眠时长/达标率）成立。当指标方向相反（如血糖、血压超标）时，**上升应配红色**，遵循「好为绿、坏为红」的语义优先原则。

### 12.3 信息展示组件色彩使用规则

1. **色彩职能分离**
   - **主色 `#2A7F8B`**：CTA / 装饰条 / 选中态 / 链接
   - **鲜艳数据色**：仅用于 KPI 数值、状态徽章、数据胶囊
   - 二者不在同一组件内同时强调
2. **背景使用弱化**：所有数据色作为背景必须使用 alpha=0.08~0.14 的透明度，不大面积填实色
3. **深浅成对**：实色用于文字/图标，弱透明背景与之配对（如 `#4388FF` 文字 + `rgba(67,136,255,0.08)` 背景）
4. **图标遵循面性 / 线性图标规范**，禁止 emoji
5. **数值字体**：使用 `tabular-nums`（等宽数字）保证多行对齐

### 13.5 图表使用原则

1. **禁用渐变**：所有图表 series/area/ring/bar 使用纯色。需要层次感时用透明度（`seriesAlpha`），不用 `LinearGradient`/`RadialGradient`

4. **不滥用 3D**：禁用 ECharts 的 3D 效果（违反扁平化原则）
5. **空状态降级**：无数据时显示 EmptyState 组件，不显示空图表骨架

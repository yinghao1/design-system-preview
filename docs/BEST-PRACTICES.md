# 组件使用示例与最佳实践

> 本文档提供各组件的典型使用场景、推荐做法和常见错误  
> 创建日期：2026-05-22

---

## 1. 布局组件

### 1.1 Layout 布局容器

**推荐场景**：

```html
<!-- 经典后台管理布局 -->
<div class="layout">
  <aside class="layout__sider">
    <!-- 侧边导航 -->
  </aside>
  <div class="layout__main">
    <header class="layout__header">
      <!-- 顶部栏：面包屑 + 用户信息 -->
    </header>
    <main class="layout__content">
      <!-- 页面内容 -->
    </main>
  </div>
</div>
```

**最佳实践**：
- 侧边栏折叠时使用 64px 宽度，保留图标导航
- Content 区域始终使用 `background: #FAFAFA` 与侧边栏区分
- 移动端（< lg）自动隐藏侧边栏，使用汉堡菜单触发

**反模式**：
- ❌ 不要在 Content 区域使用白色背景（与侧边栏混淆）
- ❌ 不要让 Header 高度超过 56px
- ❌ 不要在侧边栏中放置过多层级（最多 2 级）

### 1.2 Grid 栅格系统

**推荐场景**：

```html
<!-- 表单两列布局 -->
<div class="row" style="gap: 16px">
  <div class="col-12"><!-- 左侧字段 --></div>
  <div class="col-12"><!-- 右侧字段 --></div>
</div>

<!-- 仪表盘卡片布局 -->
<div class="row" style="gap: 16px">
  <div class="col-6"><!-- 统计卡片 --></div>
  <div class="col-6"><!-- 统计卡片 --></div>
  <div class="col-6"><!-- 统计卡片 --></div>
  <div class="col-6"><!-- 统计卡片 --></div>
</div>
```

**最佳实践**：
- 使用 16px 或 20px 作为默认 gutter
- 移动端使用 col-24（全宽），桌面端按需分列
- 表单推荐 col-12（两列）或 col-8（三列）

## 2. 导航组件

### 2.1 Tabs 标签页

**推荐场景**：

| 场景 | 推荐类型 | 说明 |
|------|----------|------|
| 页面内容切换 | Line 型 | 下划线激活，最常用 |
| 卡片内分区 | Card 型 | 背景色区分，适合紧凑空间 |
| 可动态增减 | Line + 可关闭 | 多标签页管理 |

**最佳实践**：
- 标签数量控制在 2-7 个
- 标签文字控制在 2-6 个字符
- 超出宽度时使用滚动模式，不要换行
- 默认激活第一个标签

**反模式**：
- ❌ 不要在标签中使用过长文字
- ❌ 不要嵌套使用 Tabs（Tabs 内再放 Tabs）
- ❌ 不要用 Tabs 替代导航菜单

### 2.2 Collapse 折叠面板

**推荐场景**：

| 场景 | 推荐模式 | 说明 |
|------|----------|------|
| FAQ 页面 | 手风琴模式 | 同时只展开一个 |
| 表单分组 | 基础模式 | 可同时展开多个 |
| 设置页面 | 无边框模式 | 更轻量的视觉 |

**最佳实践**：
- 默认展开第一个面板（如果内容重要）
- 面板标题简洁明了，不超过 20 个字符
- 面板内容不要过长（建议不超过屏幕高度的 50%）

## 3. 数据展示组件

### 3.1 Descriptions 描述列表

**推荐场景**：

```html
<!-- 详情页基本信息 -->
<div class="descriptions descriptions--bordered">
  <div class="descriptions__title">基本信息</div>
  <div class="descriptions__body" style="grid-template-columns: repeat(3, 1fr)">
    <div class="descriptions__item">
      <span class="descriptions__label">姓名</span>
      <span class="descriptions__content">张三</span>
    </div>
    <!-- 更多字段... -->
  </div>
</div>
```

**列数选择**：

| 信息量 | 推荐列数 | 适用场景 |
|--------|----------|----------|
| 少（≤6 项） | 2 列 | 简单详情 |
| 中（7-12 项） | 3 列 | 标准详情页 |
| 多（>12 项） | 4 列 | 复杂信息展示 |

**最佳实践**：
- 标签文字统一使用 uppercase + 0.02em letter-spacing
- 数字类内容使用 mono 字体
- 长文本内容可跨列显示

### 3.2 Table 高级功能

**树形表格使用场景**：
- 组织架构展示
- 文件目录浏览
- 多级分类管理

**可编辑表格使用场景**：
- 批量数据录入
- 快速修改单个字段
- 表格内联编辑

**最佳实践**：
- 树形表格缩进不超过 4 层
- 可编辑单元格需要明确的视觉提示（hover 时显示编辑图标）
- 固定列不超过 2 列（左 1 + 右 1）

## 4. 表单组件

### 4.1 Form 表单容器

**布局选择**：

| 场景 | 推荐布局 | 说明 |
|------|----------|------|
| 标准表单 | Horizontal | 标签在左，桌面端默认 |
| 移动端 | Vertical | 标签在上，节省横向空间 |
| 筛选栏 | Inline | 多字段横排，紧凑 |
| 长标签 | Vertical | 标签超过 6 个字时 |

**最佳实践**：
- 必填字段使用红色 * 标记
- 错误提示紧跟在输入框下方
- 帮助文本使用 ink-500 色，不要与错误提示混淆
- 表单提交按钮放在表单底部，与标签对齐

### 4.2 DatePicker 日期选择器

**推荐场景**：

| 场景 | 推荐配置 | 说明 |
|------|----------|------|
| 单日期选择 | 基础模式 | 选择一个日期 |
| 日期范围 | 范围模式 | 开始日期 ~ 结束日期 |
| 快速筛选 | 带快捷选项 | 今天/本周/本月 |
| 历史查询 | 禁用未来日期 | 只能选过去的日期 |

**最佳实践**：
- 日期格式统一使用 `YYYY-MM-DD`
- 使用 mono 字体显示日期值
- 提供"今天"快捷按钮
- 范围选择时高亮中间日期

### 4.3 Upload 上传

**推荐场景**：

| 场景 | 推荐模式 | 说明 |
|------|----------|------|
| 单文件上传 | 按钮上传 | 简单直接 |
| 批量上传 | 拖拽上传 | 大面积拖放区域 |
| 图片上传 | 图片墙 | 缩略图预览 |

**最佳实践**：
- 明确标注文件类型和大小限制
- 上传中显示进度条
- 上传失败提供重试按钮
- 文件列表显示文件名 + 大小 + 状态

## 5. 反馈组件

### 5.1 Message vs Notification vs Toast

| 组件 | 位置 | 时长 | 适用场景 |
|------|------|------|----------|
| Message | 顶部居中 | 3 秒 | 轻量操作反馈（保存成功、删除成功） |
| Notification | 右上角 | 4.5 秒 | 重要系统通知（新消息、任务完成） |
| Toast | 右下角 | 可配置 | 带操作的提示（撤销、查看详情） |

**选择原则**：
- 用户主动操作的反馈 → Message
- 系统推送的通知 → Notification
- 需要用户操作的提示 → Toast

### 5.2 Message 全局提示

**最佳实践**：
- 文案简洁，不超过 20 个字符
- 成功消息 3 秒自动关闭
- 错误消息可适当延长到 5 秒
- 同时最多显示 3 条消息

## 6. 通用原则

### 6.1 组件组合推荐

| 页面类型 | 推荐组件组合 |
|----------|-------------|
| 列表页 | Layout + Table + Form(inline) + Message |
| 详情页 | Layout + Descriptions + Tabs + Collapse |
| 表单页 | Layout + Form(horizontal) + DatePicker + Upload |
| 仪表盘 | Layout + Grid + Statistic + Progress |

### 6.2 响应式适配清单

- [ ] 表单：桌面 horizontal → 移动 vertical
- [ ] 栅格：桌面多列 → 移动单列
- [ ] 表格：桌面完整 → 移动横向滚动
- [ ] 侧边栏：桌面展开 → 移动收起
- [ ] Tabs：桌面全部显示 → 移动滚动模式
- [ ] Descriptions：桌面多列 → 移动单列

### 6.3 无障碍检查清单

- [ ] 所有交互元素可通过 Tab 键聚焦
- [ ] 焦点状态使用 cdx-700 + 3px ring shadow
- [ ] 表单字段关联 label（for/id 或嵌套）
- [ ] 错误提示使用 aria-describedby 关联
- [ ] 弹层打开时焦点移入，关闭时焦点回到触发元素
- [ ] 颜色对比度满足 WCAG AA（4.5:1）

健康提醒卡

面向医疗健康场景的提醒信息流。以染色图标圆区分提醒类型，日期胶囊浮于行右上角；异常项遵循「危急值三重编码」（颜色 + 图标 + 文字），关键指标带单位与参考区间。信息流可滚动，顶部在滚动后淡出遮罩。

安装

在页面中引入组件样式与 Tailwind 配置即可。健康提醒卡额外依赖 design-system/assets/health-alerts.css（含滚动信息流与顶部淡出遮罩）。

使用方式

在 Code 标签页复制完整标记，替换其中的文案与数据即可。提醒类型通过 health-alert-icon 的背景类区分：

  • bg-danger — 危急异常（高心率、低血氧），须配合 health-alert-crit「危急」标签实现三重编码。
  • bg-warn — 需关注（信息变更、用药提醒）。
  • bg-success — 正常/完成（实验室结果正常）。
  • bg-cdx / bg-violet — 中性信息（用药、睡眠）。

异常指标必须带单位与参考区间；危急值需同时出现颜色、图标、文字，禁止仅靠颜色表达异常（见 DESIGN.md §0.5 医疗行业使用约定）。

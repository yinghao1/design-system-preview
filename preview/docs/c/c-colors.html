使用规则

  1. 60-30-10 法则：60% 暖灰背景 + 30% 白色面与深色文字 + 10% 蓝色强调。
  2. 对比度：主文字与背景 ≥ 7:1（AAA）；次要文字 ≥ 4.5:1（AA）。
  3. 状态色不做大面积背景填充，仅用于小标签、图标、进度条。
  4. 渐变仅用于品牌元素（启动页、高级功能入口），不用于普通按钮与图表。
  5. 色彩职能分离：主色负责 CTA / 装饰条 / 选中态；鲜艳数据色仅负责 KPI 数值、状态徽章。二者不在同一组件内同时强调。
  6. 深浅成对：数据色作为背景时使用 alpha 0.08–0.14，实色用于文字与图标。
  7. 趋势色语义优先：「上升 = 绿」仅在「数值越大越好」的指标上成立；血压、血糖等超标即坏，上升必须配红。

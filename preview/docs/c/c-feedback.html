使用规则

  1. Toast 只用于短暂、无需决策的反馈；需要用户确认的一律用 Modal。
  2. 同一时刻只允许一个 Toast，连续触发时覆盖而非堆叠。
  3. Modal 的破坏性操作按钮必须红色且位于右侧，取消在左。
  4. Sheet 必须提供「取消」出口；点击遮罩或下滑也可关闭。
  5. 加载超过 300ms 才显示 Spinner；超过 1s 显示骨架屏而非空白。
  6. 空状态必须给出下一步动作（如「立即上传」），不能只有说明文字。

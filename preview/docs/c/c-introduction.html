C 端移动概述

RUNDA ToC 移动端设计组件系统（v1.6.0），基于 iOS 应用截图逆向分析。与 B 端 PC 端共享同一套中性色阶、背景纹理与品牌主色 #2A7F8B，形成「一个品牌、两种端形态」的统一界面语言。

Design Principles · 六条设计原则
浅色为主
暖灰基底 #FAFAFA，卡片纯白，通过阴影区分层级而非色差。
蓝色聚焦
单一强调色引导注意力，仅用于 CTA、链接、进度与关键状态。
卡片承载
信息以卡片为单元组织，间距 12pt，内边距 16pt。
呼吸感
大量留白，段落间距 ≥ 24pt，列表项间距 ≥ 8pt。
渐进展示
复杂信息分层呈现：折叠、步骤指示器、骨架屏。
触觉反馈
按压缩放 0.96、高亮背景、Haptic 触感。

跨端一致性

以下视觉元素与 B 端（PC）完全一致，是两套系统共享的「品牌底座」。C 端不重新定义这些值。

共享元素B 端令牌C 端令牌
中性色阶（11 级）color.ink.50~950color.primitive.neutral
品牌主色 500color.cdx.500 #2A7F8Bcolor.primitive.primary.500

规范文件

C 端完整的令牌、组件契约与验收流程见仓库 docs/c/ 目录。

使用方式

页面需同时引入站点外壳样式与 C 端组件样式。C 端组件统一使用 c- 前缀，与 B 端类名不冲突，可在同一仓库内并存。

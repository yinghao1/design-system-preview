使用规则

  1. 任何检验数值必须同时给出单位与参考区间，缺一不可。
  2. 异常值不得只靠颜色区分，必须叠加文字（偏高/超标）或图标。
  3. 趋势色遵循「好为绿、坏为红」，指标方向相反的（血糖、血压）需反转语义。
  4. 卡片内最多承载 1 个主指标 + 1 组辅助指标，超出拆分为多张卡片。
  5. 长列表使用分页或虚拟滚动，单屏渲染节点不超过 50 个。

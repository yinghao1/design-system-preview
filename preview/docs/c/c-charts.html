使用原则

  1. 禁用渐变：series / area / ring / bar 全部纯色，需要层次感时用透明度。
  2. 主色优先：单系列图表强制使用 #2A7F8B。
  3. 色彩有意义：涨绿跌红，仅在「数值越大越好」语义下成立。
  4. 禁用 3D：不使用 ECharts 3D 效果，违反扁平化原则。
  5. 多系列 ≤ 4 条，超出改为小倍数图（small multiples）分屏展示。
  6. 空状态降级：无数据显示 EmptyState，不显示空坐标系骨架。

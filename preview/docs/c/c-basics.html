使用规则

  1. 一个屏幕内只允许一个主按钮；同级操作使用次要/描边按钮。
  2. 破坏性操作使用 Danger，且必须在二次确认弹窗中再次出现。
  3. 按钮文案不超过 8 个汉字，避免换行。
  4. 禁用态必须保留原位置，不使用 display:none 造成布局跳动。
  5. 图标按钮必须有 aria-label；纯图标不可作为唯一的操作入口文案。

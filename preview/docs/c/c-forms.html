使用规则

  1. 标签置顶（不用浮动标签），错误提示紧贴输入框下方 6pt。
  2. 错误提示必须说明如何修正，禁止只写「输入有误」。
  3. 数字键盘使用 inputmode="decimal"；手机号使用 type="tel"。
  4. 开关类控件点击整行均可切换，不只点开关本体。
  5. 表单提交按钮固定在安全区之上，并提供 loading 态防止重复提交。

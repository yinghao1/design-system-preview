v2.9.0

2026-11-19
重构 规范

C 端视觉语言整体对齐 HeroUI Native

  • Token 层重建：文字改为 foreground / 次级 / muted 三档（#2C2C2E / #5F5F66 / #7C7C82，比旧版纯黑更柔和）；新增三级灰阶 surface（#FAFAFA → #F4F4F5 → #EDEDEE）；边框收敛为 #E1E1E3。
  • 圆角系统：按 HeroUI --radius: 8px 基准展开 --c-r-xs~4xl（4/6/8/12/16/24/32）。按钮 12→24、折叠面板 16→24、Chip/Capsule 全胶囊→16 圆角矩形、输入框→14。
  • 阴影系统：改用 HeroUI 的 surface / overlay 两套多层极柔阴影，替代原单层硬投影（0 4px 12px rgba(0,0,0,.08)）；卡片、图表卡、任务卡、价格卡、Banner 统一 surface。
  • 字级系统：新增 .c-h1~.c-h6 / .c-body / .c-body-sm / .c-body-xs / .c-card-title 语义类；按钮字号 17→16、字重 600→500（HeroUI 均为 medium）；列表标题 16/500、描述 13→14/muted；卡片标题 16/600→18/500。
  • 组件细节：输入框由「1px 硬边框」改为「灰底填充 + 聚焦白底描边」；折叠面板成为独立 24pt 圆角卡片、项间分割线内缩 20pt；导航/Tab 组、分段控件、弹窗、Sheet、Toast 圆角与字级同步。
  • 一致性清理：把 115 处 HTML 内联硬编码色值（#52525B / #A1A1AA / #2A7F8B 等）改为 CSS 变量，从此跟随 token 变化；移除折叠面板的内联 border-radius:0 覆盖。
  • 字号阶梯重建：废弃旧 iOS 11 级阶梯（Hero 34 / Title 28 / Body 17 …），改按 HeroUI Text 预设展开 H1 36 / H2 30 / H3 24 / H4 20 / H5 18 / H6 16 + Body 16/14/12；大数字三档统一 Semibold 600。
  • 预览页同步：字号页演示与表格、圆角演示（7 档→9 档）、阴影演示（4 档硬投影→3 档 HeroUI 复合阴影）全部按新体系重绘；色彩页中性色阶补 ink.150 #EDEDEE 并更新语义映射；各页残留的 46pt/17pt/15pt/13pt 规格文案与圆角、分割线色值说明同步为实测值。
  • 同步更新 DESIGN.md §2 色彩 / §3.2 字号阶梯 / §3.4 语义字级 / §5 圆角 / §6 阴影，与 COMPONENTS.md 开发规范第 6 条及逐组件字号说明。

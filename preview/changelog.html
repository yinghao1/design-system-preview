v2.7.4

2026-11-01
新增 文档

CLI 接入：init / add / list

  • 新增零依赖 bin/rundad.js 与根 package.json，提供 init、add、list 三个命令。
  • init 生成 design-system/：组件样式、Urbanist 字体、Tailwind token、JSON token、示例页与 README。
  • add 从组件详情页提取 <section>，输出可复制片段与带 CDN / token 的独立预览页。
  • 使用说明新增 bun / npm / pnpm / yarn 标签切换、复制按钮、新项目 / 已有项目两种命令，并标注本地运行方式。
  • 组件页代码示例的资源路径统一为 design-system/assets/；README、COMPONENT-AUDIT、DESIGN.md 同步。
